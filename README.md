



# Student Expense Tracker - Feature Branch

## Description

Student Expense Tracker is a simple Bash-based project that helps students record and manage their daily expenses.

## Features

- Add an expense
- View all expenses
- Calculate total expenses
- Exit the program

## How to Run

Make the script executable:

```bash
chmod +x expense_tracker.sh
